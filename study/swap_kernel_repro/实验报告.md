# Swap kernel 数据布局复现实验

## 实验目的

验证 GPU 与 CPU 的 KV cache block 编号不相同时，`swap_blocks` 是否只复制映射指定的完整逻辑 block，并能把换出的数据恢复到任意 GPU block。

## 测试设计

测试张量使用项目中的 KV cache 布局：

```text
[K/V, layer, physical block, token, KV head, head dimension]
```

每个坐标填入唯一的 `int32` 值，使任何维度错位都能被精确检测。实验包含两组映射：

1. 换出：GPU block `1 -> 3`，GPU block `4 -> 0`。
2. 换入：CPU block `3 -> 2`，CPU block `0 -> 5`。

除目标 block 外，其余 block 必须保持原值。

## 运行方式

```bash
source .venv/bin/activate
CUDA_VISIBLE_DEVICES=0 python study/swap_kernel_repro/test_swap_kernel.py
```

## 实验结果

两项测试均失败：

```text
test_non_identity_swap_out_copies_logical_blocks_only ... FAIL
test_round_trip_can_restore_to_different_gpu_blocks ... FAIL

Ran 2 tests
FAILED (failures=2)
```

失败发生在目标 block 的逐元素比较，CUDA 扩展编译、加载和 kernel 执行均正常完成。

## 结论

当前 `swap_blocks` 在非同编号映射下没有按逻辑 block 正确搬运数据，换出错误会继续传播到换入结果。这复现了 swap kernel 对 KV cache 实际多维布局处理错误的问题，并为下一步修复提供了可重复的回归测试。
